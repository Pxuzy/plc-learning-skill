# 运行、维护与分发边界

运行入口 `SKILL.md` 按用户问题路由到通用证据规则、讲解工作流和必要的厂商资料。直接文本讲解不调用维护脚本。事实短答无需整套手册；深讲按 P0 证据与因果要求，P1 按触发条件，P2 按帮助程度选用。四品牌索引不是解析支持证明。

| 所有者目录 | 职责与依赖 | 分发边界 |
|---|---|---|
| 根入口、references/ | 运行时资料，按需读取 | 将来按目标平台选取，保留相对链接 |
| scripts/ | 维护政策、安装、诊断；Python 标准库、Git、POSIX shell | 普通运行包默认排除 |
| .githooks/ | pre-commit 与 commit-msg 的薄入口 | 仓库维护专用，不替换宿主其他阶段 |
| evals/ | 结构检查、合成夹具、治理回归 | 不作为模型运行输入或生产工程资料 |
| docs/ | 需求、完整路线图、决策、维护说明 | 开发仓库专用，普通运行不加载 |

数据路径：暂存变更名称与 index 对象 → 路径/材料分类 → 暂存 blob 内容 → Git 有效作者与提交者；消息钩子另读取消息文件并执行同一隐私政策。候选扫描读取所有未忽略的跟踪/未跟踪文件，不改索引。敏感值与敏感文件名不进入项目门禁诊断。

本轮保留原入口、核心规则、源码夹具与案例卡；不创建尚无职责的 templates/assets 或空品牌目录，不搬旧实现、历史或私有语料。未来运行包不带 `.git`、hooks、docs、evals 和缓存；包名与元数据一致及目标平台实测属于 G，未在本轮完成。
