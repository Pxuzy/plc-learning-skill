# 模板路由（按适用条件选择）

本文件只按适用条件把请求路由到已登记模板，**不是**模板注册表：模板 ID、版本、权威正文和组合关系以[模板总索引](../references/template-index.md)为唯一登记来源。此处出现的 ID 必须能在该索引中查到；需要新增 ID 时先登记，再改本文件。只选择当前请求需要的模板，不把多个模板机械叠加。

## 适用条件路由

| ID/版本 | 呈现文件 | 适用条件 | 不适用时 | 与其它模板的关系 |
|---|---|---|---|---|
| NAV@1.0 | `project-navigation.md` | 工程跨多个对象、框架复杂，或用户尚未选定范围 | 用户已明确指定对象且无需理解更大框架时，直接走 CODE | 用户选范围后转入 CODE；本身不是代码讲解 |
| CODE@1.0 | `code-explanation.md` | 用户要求讲解 PLC 代码，且范围已明确或已选定 | 简短事实问题直接简答，不套模板 | 按需引用厂商资料；实际拆成多本时配 BOOKSET |
| BOOKSET@1.0 | `handbook-index.md` | 用户要求完整多对象手册，且实际输出拆为两本或更多 | 单本手册直接交付，不生成空索引或预留册号 | 配套各册 CODE 手册；不替代其内容 |

CODE 的正式输出规则权威是 `references/local-code-explanation.md`，`templates/code-explanation.md` 只是其兼容呈现；BOOKSET 的单一正文是 `references/template-handbook-index.md`，`templates/handbook-index.md` 以 `template-compat` 标注为兼容呈现。呈现文件与权威正文冲突时，以权威正文为准。

## 请求与输出选择

| 用户请求 | 输出选择 | 边界 |
|---|---|---|
| 简短事实问题，未要求代码讲解 | 直接简答 | 不套模板、不生成手册 |
| 用户已明确指定对象 | CODE | 若理解更大框架并非回答所必需，不先做 NAV |
| 用户未选范围，或复杂工程需要先拆解 | NAV | 展示可选对象并**等待用户选择**；默认不创建额外导航文件 |
| 用户明确要求完整范围 | 按完整范围使用 NAV/CODE | 仅在实际拆成多册时增加 BOOKSET |
| 单个对象的详细讲解 | CODE | 不生成多册索引 |
| 多个对象被拆为多本手册 | 各册 CODE + BOOKSET | 索引登记对象、阅读顺序、跨册关系和覆盖/缺口 |

## 组合与范围

- NAV 将一页总览与工程结构地图合为导航输出。保留输入中实际存在的工程层级和原生名称；不要求所有品牌都具有相同对象、任务或网络结构。
- CODE 只覆盖用户请求或选择的范围，遵循[讲解流程](../references/workflows/explain-code.md)和[证据规则](../references/common/evidence-and-causality.md)。NAV 的结构定位不代替逐段解释。
- BOOKSET 只在存在多本手册时使用。单本手册直接交付，不生成空索引或预留册号。
- 所有模板只记录有来源支持的内容。未知、推断、受保护和未覆盖范围需明确标示；不因模板字段而臆造工程事实。

## 版本规则

模板 ID 与版本以[模板总索引](../references/template-index.md)为准，本文件不自行定义版本。文字或版式调整且不改变字段含义时升次版本；改变职责、必需字段或组合契约时升主版本，并在索引、路由与检查中同步。历史交付物不因模板更新而自动改写。
